GitHub Actions Handson

GitHub Actions を使った CI/CD ハンズオンの学習記録サイトです。

このサイト自体が GitHub Actions で自動デプロイされています!

Learning Steps

CI Step 1: Hello World

push をトリガーにワークフローを実行する基本を学んだ。

CI Step 2: Python CI

ruff (lint) と pytest (テスト) を自動実行する CI パイプラインを構築した。

CD Step 3: GitHub Pages Deploy

main ブランチにマージしたら自動でこのサイトがデプロイされる仕組みを構築した。
